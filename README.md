# 4-Stage-Pipelined-Multimedia-Unit
VHDL based multimedia processor unit with custom ALU operations

## Features
- 4-stage pipeline: IF, ID, EX, WB
- 128-bit multimedia ALU
- 32-register file
- Instruction buffer for 25-bit instructions
- C++ assembler for custom assembly instructions
- ModelSim testbenches for simulation and debugging

## Tools Used
- VHDL
- C++
- ModelSim
